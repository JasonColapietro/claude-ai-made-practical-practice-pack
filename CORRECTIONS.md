## Interface notes, October 2026

Claude is moving accounts to a newer version gradually. If a label in the book doesn't match your screen, you may have the other version. Each item below gives both.

- **Message box.** Older version: **Chat** and **Cowork** options, and a **Web search** item in the **+** menu. Newer version: neither. Claude searches the web when your question needs it.
- **Settings page for your account.** Newer: **Your Claude**. Older: **Account** or **Memory**.
- **Instructions label.** Newer: **Instructions**. Older: **Instructions for Claude**. The old Cowork **Global instructions** are merged into it.
- **Memory switch.** Newer: **Memory from chats**. Older: **Generate memory from chats**.
- **File-creation setting** (under **Settings**, then **Capabilities**). Newer: **Create and edit files**. Older: **Code execution and file creation** or **Cloud code execution and file creation**.
- **Scheduling** (Workflow 24). Newer: describe the task in a chat, then click **Schedule**. Older (Cowork): **Scheduled** in the sidebar, then **New task**.
- **Incognito chats** open in the older version, so they can't create files or run code.
- **Thinking switch** in the model menu reads **Thinking** or **Extended**, depending on the model.
- **Artifacts.** New template artifacts use **Export**. Artifacts made before September 16, 2026 keep the older copy, download and publish controls.
- **Model menu.** Next to the send button on the web and desktop. At the top of the screen in the mobile app.
