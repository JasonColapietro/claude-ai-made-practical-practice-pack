# Claude AI Made Practical: Practice Pack

The practice files for *Claude AI Made Practical: A Step-by-Step Guide for Beginners to Everyday Tasks and Practical Workflows* by Jason Colapietro (Johnny Suede Press, 2026), Volume 4 of The AI Business Builder Collection.

Each workflow in the book has a folder here, `wf01-customer-reply` through `wf24-scheduled-task`. Inside each folder:

- `wfNN-input-*`: the starting material the lesson uses (emails, notes, contracts, spreadsheets, charts)
- `prompt.txt`: the full prompt, ready to copy
- `repair-request.txt`: the fix to ask for when the first answer is weak
- `example-result.txt`: the result the book shows
- `wfNN-transfer-*` and `example-transfer-result.txt`: the second input from a different person's life, and its result
- `answer-key.txt`: for workflows with a checkable answer (tables, numbers, extractions, cleaned records)

`shared/` holds the recurring facts for Harbor & Home Cleaning, the small business used in several lessons.

All names, companies, emails and phone numbers in these files are fictional.
