I need to choose one of three cleaning-supply suppliers for my cleaning business, Harbor & Home Cleaning. I'll make the final call myself. Your job is to lay out the comparison so I can decide in one sitting.

Use only the files I attached: my needs file and the three proposals. Don't add outside information about these companies or typical prices.

Do this in order:
1. Must-haves. Make a table with one row per must-have from my needs file and one column per option. Mark each cell Yes, No or Unclear, with a few words of proof from the proposal.
2. Monthly cost. Price my usual monthly order from the needs file from each proposal, item by item. Include delivery, discounts and fees. Show the math. If an item isn't offered or a price is missing, say so and leave it out of the total. Don't estimate it.
3. Nice-to-haves. A short table in the same format.
4. Problems. List anything in a proposal that contradicts itself, any condition attached to a price, and anything in my needs file the proposals don't answer.
5. Bottom line. In 3 to 5 sentences, say which options are still in the running and what each would cost. Then list the questions I should send each one before I sign.

Keep it plain and short. No sales language. If no option meets every must-have within my budget, say so plainly instead of picking a winner.
